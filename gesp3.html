📖 打个比方：进制就是「打包方式」——十进制满 10 个换一盒，二进制满 2 个就换一盒。换算，就是把每盒装了几个数清楚。
把鼠标放到格子上，看看每位数字的作用 👆

常见 ASCII 码

📖 打个比方：ASCII 码像给每个常用字符发的「学号」（0~127），记住几个关键学号就能推算一大片；负数在计算机里不直接存负号，而是穿一件叫「补码」的马甲，这样减法就能当加法算。
💡 输入一个字符（或一个 −128~127 的数），结果马上变 👇

按位与 &：两位都是 1 才是 1

按位与：两个都是 1，结果才是 1
📖 打个比方：按位运算就是把两个二进制数上下对齐，一列一列地算——每一列只看自己这一位的 0 和 1，互相不打架。移位则像整排位一起「齐步走」：向左/向右挪 n 格，空出来的位置补 0，挤出去的位就丢掉了。
💡 换运算符、改数字马上看结果；把鼠标放到位格子上，看这一位是怎么算出来的 👆

一维数组

📖 打个比方：数组是一排编了号的储物柜，编号从 0 开始；字符串就是一排字符格子串起来，同样从 0 号数起——substr 是「从几号开始拿几个」，replace 是「从几号开始拆几个、换上新的」。
💡 点排序按钮、改数字 / 改字符串，马上看结果；把鼠标放到格子上看它的下标 👆

16 ans = ans + d * pow(base, e); // ★ 按权展开（小数也适用）
17 }

20}

🧭 三种转换，三套方法

  • 其他进制 → 十进制：按权展开。每一位乘上「基数的位数次方」（从右往左是 0 次方、1 次方、2 次方…），再全部加起来。
  • 十进制 → 其他进制：整数部分除基取余，除到商是 0，余数倒着读；小数部分乘基取整，得数顺着读。
  • 八/十六 ↔ 二：不用除也不用乘！一位八进制＝3 位二进制（8=2³），一位十六进制＝4 位二进制（16=2⁴），从右往左分组，左边不够补 0。

🧠 公式 + 口诀（这次别再忘）

(1101.01)₂ = 8+4+0+1+0+0.25 = 13.25
  • 整数部分：小数点左边从 0 次方往左数；小数部分：小数点右边从 −1 次方往右数（2⁻¹=0.5，2⁻²=0.25…）。
  • 按权展开口诀：「位从零数起，权是基数的位数次方，乘完就加」。
  • 除基取余口诀：「除基取余，除到零；余数倒读，才成功」；小数部分：「乘基取整，顺着排」。
  • 8↔2 口诀：「一拆三 / 三并一」；16↔2：「一拆四 / 四并一」。分组永远从右往左。
  • 背下 2 的幂：1 2 4 8 16 32 64 128 256 512 1024，手算就飞快。

🔤 常见 ASCII 码

必背：空格 = 32；'0' = 48；'A' = 65；'a' = 97
  • '0'~'9' ＝ 48~57（数字字符）；'A'~'Z' ＝ 65~90（大写字母）；'a'~'z' ＝ 97~122（小写字母）。
  • 大小写相差 32：大写 + 32 ＝ 小写（'A' + 32 ＝ 'a'），小写 − 32 ＝ 大写。
  • 易错：'7' 是字符（ASCII 55），7 是整数；'7'-'0' ＝ 55−48 ＝ 7。
  • 常考控制字符（中文名）：0 ＝ NUL 空字符；7 ＝ BEL 响铃；8 ＝ BS 退格；9 ＝ HT 水平制表符；10 ＝ LF 换行；13 ＝ CR 回车；27 ＝ ESC 退出；127 ＝ DEL 删除。
  • 标点符号也各占一号：'!' ＝ 33、'+' ＝ 43、'-' ＝ 45、'.' ＝ 46、'=' ＝ 61、'?' ＝ 63……都在字母区前面或后面。

🧮 原码 / 反码 / 补码

  • 正数：原码 ＝ 反码 ＝ 补码。8 位 +5 ＝ 00000101。
  • 负数：原码 →（符号位不变、其余位取反）→ 反码 →（+1）→ 补码。8 位 −5：原码 10000101；反码 11111010；补码 11111011。
  • 补码的意义：让计算机把减法变加法；同时解决原码/反码里 +0、−0 两个零的问题。
        +0         −0
原码  00000000   10000000
反码  00000000   11111111
补码  00000000   ← 只有一个 0

🔐 26 个字母密码（凯撒密码）

(c−'a'+k) % 26 + 'a'
  • 右移 k（加密）：(c-'a'+k)%26+'a'；左移 k（解密）：(c-'a'-k+26)%26+'a'（先 +26 防止减成负数）。
  • %26 实现循环：26 个字母转一圈回到起点——z+1→a、z+2→b；k=25 时每个字母都变成前一个。
  • 大小写：大写字母把公式里的 'a' 换成 'A'（'A'~'Z' ＝ 65~90）。
  • 例：k=3 时 cat → fdw；xyz 右移 3 绕回开头 → abc。解密＝反向移，密文再左移 k 就还原。

🕵️ 凯撒解密：用已知明文破译新密文

d ＝ ((明文[0]−密文[0])%26＋26)%26　→　(c−'A'+d)%26+'A'
  • 题意：给一对已破解的「明文 ↔ 密文」，它们与待破解密文偏移量相同——先用这对字母求出偏移量，再拿它还原新密文。
  • 第一步求 d：d ＝ 明文[0]−密文[0]。例：'A'−'D' ＝ −3，是负数！用 (d%26+26)%26 掰正成 23——在 26 格圆环上，往后走 23 格 ＝ 往前走 3 格。
  • 第二步解密：密文每个字母 (c-'A'+d)%26+'A'（大写版公式）；%26 让加过头的编号绕回开头（密文 A＋23 → X）。
  • 验证样例：W→T、K→H、H→E…；加密时 X→A、Y→B、Z→C 的绕回，解密时正好「倒放」回来。
  • 易错：忘记掰正负数！C++ 里 −3 % 26 ＝ −3（不是 23），不减不加 26 的话编号会算成负数、结果全错。

🧰 三个小实践，一个套路

  • 凯撒加密：把每个字母放到 26 个字母的「圆环」上走 k 步，(c-'a'+k)%26+'a'。
  • 数字映射：char('a'+x) 把编号变字母（0→a、1→b、…、25→z）；反向 c-'a' 把字母变编号。
  • 大小写转换：同一种 ±32 就能互转，因为 'a'=97、'A'=65，正好相差 32。
  • 共同点：都在做「字符 ↔ 整数」的换算——字符做加减时，用的就是它的 ASCII 编号。

🖨 格式化输出：printf 的「座位表」

printf("%3d", x)　printf("%-4d", x)　printf("%.2f", x)
  • %3d 右对齐：给整数留 3 格座位，数字靠右站，左边补空格——打印矩阵/表格全靠它对齐：printf("%3d%3d%3d\n", a[i][0], a[i][1], a[i][2]);
  • %-4d 左对齐：占 4 格、靠左站，右边补空格；负号 ＝ 靠左。
  • 宽度只是「至少这么宽」：1234 用 %3d 不会砍成 123，格子自动变宽。
  • %.2f 保留两位小数：自动四舍五入（看第 3 位：≥5 进 1，＜5 丢掉）；位数不够补 0（1.5 → 1.50）。
  • 小陷阱：2.675 → 2.67 不是 bug——小数存的是近似值（2.67499…）。

👀 一眼看懂：位对位，各算各的

  • & 按位与：两位都是 1，结果才是 1；有一个 0 就是 0。
  • | 按位或：有一个是 1，结果就是 1；两个都是 0 才是 0。
  • ^ 按位异或：相同为 0、不同为 1（像「不进位的加法」）。
  • 关键动作：把两个数的二进制上下对齐，一列一列各算各的，互不打架。

🧠 移位：×2 和 ÷2 的快车道

x << n ＝ ×2ⁿ　　x >> n ＝ ÷2ⁿ（非负整数）
  • 左移 <<：整排位向左挪 n 格，右边空位补 0，挤出去的高位就没了。
  • 右移 >>：整排位向右挪 n 格，左边空位补 0，丢掉的低位就是「余数」。
  • 例：13 << 2 ＝ 52（13×4）；50 >> 2 ＝ 12（50÷4＝12.5，整数除法舍去小数）。
  • 口诀：「左移翻倍，右移减半；挪几格就乘除 2 的几次方」。

🧰 四个必会套路

  • x & 1：判断奇偶 —— 结果 1 是奇数、0 是偶数（看的就是个位）。
  • x & (1<<k)：判断第 k 位 —— 非 0 就是 1。
  • x | (1<<k)：把第 k 位置 1，其他位不变。
  • x ^ (1<<k)：把第 k 位翻转（0 变 1、1 变 0），其他位不变。
  • 异或两条性质：a ^ a ＝ 0（自己异或自己归零）、a ^ 0 ＝ a（和 0 异或不变）——所以「找单独的数」（成对消去）和「不借临时变量交换两数」（a^=b; b^=a; a^=b;）都靠它们。
  • 位号从 0 数起：1<<0＝1、1<<3＝8、1<<7＝128。

🪜 优先级：一个式子里谁先算

括号 > 单目 > 乘除模 > 加减 > 移位 > 比较 > 位运算（& → ^ → |）> 逻辑 > 赋值
  • 最容易踩的坑：== 比 & 高——x & 1 == 0 实际是 x & (1==0) ＝ x & 0，永远得 0。
  • 第二坑：加减比移位高——1 << 2 + 1 是 1 << (2+1) ＝ 8，不是 5。
  • 位运算内部排队：& 最高、^ 居中、| 最低，所以 x & 3 | 4 先 & 后 |。直觉：& 像「乘」（掩码筛选）、^ 像「加」（不进位加法）、| 像「合并」（最后拼装）——对应 × > + > 合并的松紧顺序。
  • 综合题：3 & 7 | 15 ^ ~11——先算 ~11（→ −12），再 3&7（→ 3）、15^−12（→ −5），最后 3|−5 ＝ −5（−5 的低两位本来就是 1，OR 不改变）；变量版 a & b | c ^ ~d（a=3,b=7,c=15,d=11）先代入，结果同为 −5。
  • 进阶题：!a & b<<c ^ d | e（a=0,b=2,c=11,d=7,e=5）——顺序 ! → << → & → ^ → |：!0=1 → 1&(2<<11)=1&4096=0 → 0^7=7 → 7|5 ＝ 7。
  • 移位常用不着括号：x | 1<<3 天然是 x | (1<<3)；(1<<3)-1 造出低 3 位全 1 的掩码 7。
  • 保险做法：记不住就都加括号——括号永远最优先，还能让读代码的人一眼看懂。

💻 C++ 易错点

  • &、|、^ 的优先级比 == 还低：混合比较要主动加括号，写 (x & 1) == 1。x & 1 == 0 实际是 x & (1==0) ＝ x & 0，永远得 0，全错！
  • cout 里输出移位结果也要加括号：cout << (x << 1)，不然 << 会先被当成输出符。
  • | 置 1 和 ^ 翻转的区别：那一位已经是 1 时，| 保持不变，^ 会把它翻成 0。
  • 移位是整数运算；负数的移位行为和补码有关，本页和竞赛里一般只对非负整数用。

🧇 二维数组：一格一格的表格

int a[2][3];　→　a[0][0] ~ a[1][2]
  • a[行][列]：两个下标都从 0 数起；int a[2][3] ＝ 2 行 3 列共 6 格，行号 0~1、列号 0~2。
  • a[0] 是第 0 行——它自己就是一个一维数组；a[0][1] ＝ 第 0 行第 1 格。
  • 两层循环遍历：外层固定行 i，内层走列 j——for(i…) for(j…) printf("%3d", a[i][j]); 一行打完 printf("\n") 换行，打印出来就是整齐的表格。
  • 初始化按行给：int a[2][3] = {{5,21,134},{7,3,42}}; 外层大括号＝行，内层＝这一行的数；给不满自动补 0。
  • sizeof(a) ＝ 行 × 列 × 4 字节（2×3×4 ＝ 24）；行数可以不写（编译器数大括号），列数必须写：int a[][3] = {…} ✓。

📦 一维数组：一排编了号的格子

int a[10];　→　a[0] ~ a[9]
  • 10 个元素，下标 a[0] ~ a[9]：从 0 数起，最大到 9 —— 不是 a[1] ~ a[10]，写 a[10] 就越界了。
  • sizeof(a) ＝ 40：10 个元素 × 每个 int 4 字节。sizeof 量的是整个数组，跟放进去几个数无关。
  • 定义的 5 种写法：int a[10]; 只开格子（全局自动清 0，局部是残留值）；int a[10] = {}; 全部清零；int a[5] = {5,2,8,1,9}; 逐格填；int a[5] = {5,2}; 只给前 2 个、剩下自动补 0；int a[] = {5,2,8,1,9}; 不写个数，编译器数出来是 5 格。舞台上演示 👆
  • 数组大小必须是「整数常量表达式」：数字可以（int a[10]）、字符常量也可以——int b['A'] 就是 int b[65]（'A' ＝ 65）；浮点数不行（float d[10.0] ✗）；省略长度 [] 就必须配初始化列表（int c[]; ✗，int c[] = {1,2,3}; ✓）。👇 舞台底部有道真题，试一试！
  • 整体排序：sort(a, a+n) 把 a[0] ~ a[n-1] 从小到大排好。
  • 区间排序：sort(a+l, a+r+1) 只排 a[l] ~ a[r]。sort 的右边界是开区间：想排到 a[r]，就得写 r+1。

🔤 字符串：五个最常用操作

s.length() 长度　s[i] 访问字符　s.substr(pos, len) 取子串　s.find(t) 查找　s.replace(pos, len, t) 替换
  • s.length() / s.size()：字符个数（两个写法一个意思）；s[i] 访问第 i 个字符，下标从 0 数起。
  • s.substr(pos, len)：从 pos 号开始，取 len 个字符。
  • s.find(t)：返回 t 出现的开头下标；找不到返回 string::npos（一个特殊的大数），判断写 s.find(t) == string::npos。
  • s.replace(pos, len, t)：把从 pos 开始的 len 个字符换成 t，会改掉 s 本身。

💻 背这个例子：s ＝ "abcdef"

s.length()           →  6
s.substr(2, 3)       →  "cde"
s.find("de")         →  3
s.find("xy")         →  string::npos（找不到）
s.replace(2,3,"XYZ") →  "abXYZf"
  • 口诀：「位置从 0 数，长度是数量」——substr / replace / find 的位置全都从 0 号数起。
  • 易错 ①：find 找不到返回 string::npos，别拿它当普通 −1 用；「找没找到」就和 npos 比。
  • 易错 ②：s.size() 是字符数量；sizeof(s) 是 string 对象本身的大小（比如 32），和内容长短无关。

✂️ 实践：字符串分割（2026·9 三级 T2）

getline(cin, s)　第 k 次分割：s.find(k 个空格)　左侧逐字符输出，右侧拼成新的 s
  • 规则：第 1 次分割找 1 个连续空格，第 2 次找 2 个，第 3 次找 3 个……每次把用来分割的空格舍弃，左侧部分输出，右侧继续处理；找不到所需长度的连续空格就停止。
  • 样例：输入 sdfd 55 55 99312 → 输出 3 行：sdfd、55 55、 99312。第 3 行开头的空格要保留——第 2 次分割只舍弃 2 个空格，剩下的这个空格不是分隔符，属于最后剩余的部分。
  • 特殊：连一次分割都没成功（找不到 1 个连续空格）→ 直接输出原字符串；分完以后别忘了输出最后剩余的右侧部分。
  • 输入有空格 → 必须用 getline(cin, s) 整行读；cin >> s 会在第一个空格处停住，后半截就丢了。
  • 易错：连续空格可能比需要的多——多出来的不会消失，会留在下一段的开头（样例第 3 行开头的空格就是这么来的）；找分割点直接拼出 k 个空格 去调 s.find，找不到返回 npos，正好拿来当停止条件。舞台上演示 👆
