指针：& 与 *

📖 打个比方：变量是一间贴着门牌号的房子，门牌号就是地址；指针 p 是一张写着别人家门牌号的小纸条，顺着纸条找上门（*p），就能看也能改里面的东西。结构体则是把几个大小不同的房间打包成一栋小楼，报房间名就能进出（s.name）。
💡 蓝色箭头就是指针：从 p 出发，指向 p 里存的那个地址；点按钮、改数字试试 👆

冒泡排序：相邻比较，大的往后「冒」

📖 打个比方：给一排同学按身高排队——冒泡是「相邻两人比一比，高的往后站」；选择是「每轮挑最矮的放到队头」；插入是「新同学插进已排好的队伍」；归并是「对半分成两队，各自排好再合并」；堆排是「把队伍堆成金字塔，每轮取塔顶最高的人放到队尾」。

递推：从起点一步步推

📖 打个比方：递推像多米诺骨牌——推倒第一块（初始条件），后面每一块都由前一块带倒（递推关系式），不用回头，顺着算到底。复杂度则是数一数算法要干多少「基本活儿」，只看随 n 增长的趋势：多项式级跑得动，指数级（O(2ⁿ)）会爆炸。

4void merge(int a[], int l, int m, int r) { // 合并 a[l~m] 与 a[m+1~r]
5 int temp[105], i = l, j = m + 1, k = 0;
6 while (i <= m && j <= r) // 两队都没空：比队头
7 if (a[i] <= a[j]) temp[k++] = a[i++]; // ★ 左队头小，出队
8 else temp[k++] = a[j++]; // ★ 否则右队头出队
9 while (i <= m) temp[k++] = a[i++]; // 某队空了，剩下的接上
10 while (j <= r) temp[k++] = a[j++];
11 for (int t = 0; t < k; t++) // 写回原数组
12 a[l + t] = temp[t];
13}

4void siftDown(int a[], int i, int size) { // 把 a[i] 下沉到合适位置
5 while (2 * i + 1 < size) { // 有孩子才需要调
6 int big = 2 * i + 1; // 先指向左孩子 a[2i+1]
7 if (2*i+2 < size && a[2*i+2] > a[big])
8 big = 2 * i + 2; // 右孩子更大就选它
9 if (a[big] <= a[i]) break; // 爸爸最大，停
10 swap(a[i], a[big]); // ★ 和较大的孩子交换，下沉
11 i = big; // 继续往下看
12 }
13}

  • 切到按列染色：同一种颜色是原来的同一列（要从下往上读），转完后横着躺成新矩阵的一行。
  • 变暗的格子 = 已经搬完的家。

🧠 公式是怎么来的？

b[j][n+1-i] = a[i][j]
  • 新行号 = 旧列号 j：同一行里从左到右的格子，转完后在新的一列里从上到下排队。
  • 新列号 = n+1-i：第 1 行转到最右边（新下标是 n），第 2 行到 n-1……行号要「倒着数」。
  • 口诀：行变列、列变行，行号倒着数。
  • 反过来，向左转（逆时针）的公式是 b[m+1-j][i] = a[i][j]，可以自己推推看。

👀 一眼看懂：怎么乘？

  • 形状规则：A 是 n×k，B 是 k×m，结果 C 是 n×m。A 的列数 = B 的行数（都是 k）才乘得起来。
  • 算 c[i][j] 时：用 A 的第 i 行（蓝框）和 B 的第 j 列（橙框），一对一相乘，再把乘积全部加起来。
  • 动画里飞进 C 格子的两个数就是当前这对乘数；C 格子里的数字一路累加，最后定格上色。
  • 默认 A 按行染色、B 按列染色，正好对应它们各自"贡献"的方向。

🧠 公式是怎么来的？

c[i][j] = a[i][1]·b[1][j] + … + a[i][k]·b[k][j]
  • 一句话：A 的行 × B 的列，对应相乘再求和（这叫「点积」）。
  • 所以 C++ 要用三重循环：外两层 i、j 挑结果格子，最内层 t 一对一对地乘、加。
  • 口诀：「行乘列，加到底」。
  • 为什么中间必须是同一个 k？配对时 A 的列和 B 的行要一个对一个，数量必须相等。

👀 一眼看懂：三条「斜线」

  • 主对角线：左上 → 右下，关系是 i == j（默认填 i×10+j，所以是 11、22、33、44）。
  • 反对角线：右上 → 左下，关系是 i + j == n + 1（14、23、32、41——每往下一行就往左一列，和不变）。
  • 其他对角线：给定一个元素 (i0, j0)，它所在斜线上所有格子的 i − j 都等于 i0 − j0；沿斜线从左上端走到右下端，打印除它自己以外的所有元素。
  • 动画：「其他对角线」模式下整张棋盘按 i − j 染成淡斜条纹（同一条斜线同色），蓝框是给定的元素，走过的格子亮起并打印；主 / 反对角线模式仍是逐格扫描，满足关系的格子亮起。

🧠 i 和 j 的关系（对角线速查）

主对角线 i == j　·　反对角线 i + j = n+1　·　平行线 i − j = k
  • 反对角线为什么是 i + j == n + 1：从 (1, n) 到 (n, 1)，每往下一行就往左一列，行+列不变。下标从 0 数起时是 i + j == n − 1，两种都要认识。
  • 给定元素求斜线：k = i0 − j0 恒定 → 对每个 x 算 y = x − k 反解列号；与反对角线平行的斜线：i + j = s 恒定 → j = s − i。
  • 易错点 ①：斜线会伸出方阵，必须判 1 ≤ j ≤ n（k > 0 时也可以让 i 从 k+1 开始）。
  • 易错点 ②：对角线一般只对方阵（n×n）谈，长方形矩阵先看题意。
  • 常见变式：主 / 反对角线求和、判断对称（a[i][j] == a[j][i]）、转置——全是 i 和 j 的关系游戏。

🧠 dx / dy 位移矩阵：8 个方向一个循环搞定

(x, y) = (i + dx[t], j + dy[t])　t = 0…7

👀 一眼看懂：指针与结构体

  • 📦 变量是贴着门牌号的盒子：值住在里面，&a 是门牌号（地址）。
  • 🧭 指针 p 是一张写着别人家门牌号的纸条：int *p = &a; —— p 里存的是地址，不是值。
  • 🚪 *p 顺着纸条找上门：看到、改到的都是 a 本尊 —— *p = 99; 之后 a 也变成 99。
  • 🏠 结构体 struct：把几个不同类型的成员打包成一个新类型，像一间「三室一厅」：s.name、s.age、s.score。

🎯 & 和 * 是一对逆操作

&a 取地址　·　*p 取内容　·　& 和 * 抵消：*&a 就是 a
  • &a 读「a 的地址」；*p 读「p 指向的东西」—— 一个往出抄门牌，一个按门牌进门。
  • 两个 * 含义不同：声明 int *p 里的 * 表示「p 是指针」；使用时 *p 表示「解引用（进门）」。
  • 指针有类型：int* 存 int 变量的地址，Student* 存结构体的地址，不能乱指。
  • 数组和指针是近亲：a[i] 本质就是 *(a + i) —— 所以数组传进函数，函数里改它，main 里也变。
  • p = a 之后，p[i]、*(p+i) 与 a[i] 完全等价；p+1 跳的是一整个元素（int 就是 4 字节），不是 1 字节。

🔁 为什么 swap 必须传指针？

传值 = 复印件　·　传地址 = 本尊
  • 只传值：mySwap(x, y) —— 函数拿到的是复印件，换得再热闹，main 里纹丝不动。
  • 传地址：mySwap(&x, &y) —— 函数里 *px、*py 摸到的就是本尊，一步到位真交换。
  • 三步口诀：tmp = *px; *px = *py; *py = tmp;（先抄一份，再各就各位）。
  • 顺手记牢：数组名传进函数也会退化成地址 —— 所以函数里改数组元素，外面看得见。

📦 结构体：成员怎么访问

变量.成员　·　指针->成员（等价 (*指针).成员）
  • struct 定义「图纸」；Student s = {"Lei", 12, 98}; 按顺序给初值。
  • 普通变量用点：s.age++；指针用箭头：p->age++，等价于 (*p).age++。
  • 结构体也能开数组：Student arr[3];，用 arr[i].name 访问 —— 姓名成绩绑在一起排序就靠它。
  • 结构体整体赋值是逐成员复印：s2 = s; 之后两者互不影响。

🧩 结合应用：函数里改结构体 + 成绩排序

  • 在函数里改结构体成员：传值改不动（复印件）；void grow(Student *p) 用 p->age++，或 void grow(Student &r) 用 r.age++ —— 引用是「别名」，写法像传值、效果像传地址。
  • 只读大结构体时传 const Student &s：既省拷贝开销，又保证改不了原数据。
  • 结构体数组排序：比较用成员（a[j].score > a[mi].score），交换必须整条记录一起换（Student t = a[i]; a[i] = a[mi]; a[mi] = t;），名字和分数才不会错位。
  • 输出时逐成员打印：cout << a[i].name << a[i].score —— 结构体数组 + 排序是「复合数据」题的标准套路。

⚠ 易错点盘点

  • 空指针解引用：p = NULL 之后再 *p —— 程序可能直接崩；用之前先让 p 指个真变量。
  • 野指针：只声明不赋值（int *p;）就 *p = 3; —— 值写到不知道哪儿去了。
  • struct 定义漏分号 → 报错常指到下一行，很难查。
  • 指针类型要匹配：double* 别去存 int 变量的地址。
  • 打印地址是 cout << p；打印指向的值才是 cout << *p，别混。

👀 一眼看懂：五种排序

  • 🫧 冒泡排序：从头到尾相邻比较，顺序不对就交换；每轮把当前最大的「冒」到未排序部分的最后。
  • 🔍 选择排序：每轮从未排好的部分找到最小值，放到当前位置——左边就位一个，范围缩一格。
  • 🃏 插入排序：像整理手牌——每次摸起一张新牌，把前面比它大的往后挪，把它插进已排好的部分。
  • 🧬 归并排序进阶：一直对半分到只剩 1 个数，再把相邻两条有序队伍（蓝条 / 橙条）合并成一条。
  • ⛰️ 堆排序进阶：数组当成完全二叉树，先调成大顶堆（爸爸 ≥ 孩子），每轮把堆顶最大值换到末尾。

🧠 基础三件套：循环边界怎么写

冒泡 j < n−1−i　·　选择 j = i+1 … n−1　·　插入 while (j ≥ 0 且 a[j] ＞ key)
  • 冒泡：外层 n−1 轮；内层 j < n-1-i——右边 i 个已经冒好，不用再比。
  • 选择：内层从 i+1 扫到 n−1；mi 记的是下标；最后 if (mi != i) 才交换，每轮只换一次。
  • 插入：key = a[i] 摸起来；while (j >= 0 && a[j] > key) 大数往后挪；a[j+1] = key 插入。
  • 易错：内层少写 -1 会比到不存在的 a[n]（越界）；插入里把 j >= 0 和 a[j] > key 顺序写反，会先越界再判断。

🧬 进阶排序：分治与堆（后续级别）

归并 O(n log n) 稳定　·　堆排 O(n log n) O(1)空间
  • 归并：合并就是双指针比队头、小者出队；稳定 O(n log n)，但要 O(n) 辅助数组；稳定（相等时先取左队）。
  • 堆排：建堆 O(n)，每次取堆顶后下沉 O(log n)；整体 O(n log n)、O(1) 额外空间；不稳定。
  • 堆的下标规律（从 0 数起）：a[i] 的孩子是 a[2i+1]、a[2i+2]；最后一位「爸爸」是 a[n/2−1]。

🔍 识别方法（考场速判）

相邻比较→冒泡　找最小/最大→选择　插进已排好→插入　分半/堆顶→进阶
  • 题目说「相邻比较」→ 冒泡；说「找最小 / 最大值，放到某位置」→ 选择；说「把新元素插到已排好的序列里」「像整理扑克牌」→ 插入。
  • 说「对半分 / 合并两条有序序列」→ 归并；说「堆顶 / 完全二叉树 / 爸爸孩子 / 下沉」→ 堆排。
  • 基础三件套的时间复杂度均为 O(n²)：n 翻倍、时间约翻 4 倍。
  • 归并和堆排都是 O(n log n)：n = 10⁵ 时约 1.7×10⁶ 次操作，比 O(n²) 的 10¹⁰ 快 5000 多倍——大 n 全靠它们。

💻 怎么选？口诀记牢

  • 冒泡最直观，但交换次数多（和逆序对一样多）；选择交换最少（每轮只换一次）但不稳定；插入对基本有序的数据接近 O(n) 且稳定。
  • 归并稳定、适合链表 / 求逆序对；堆排省内存，适合「只要前 k 大」——两个都是 O(n log n)，以后学到递归再细讲。
  • 实战里 C++ 直接 sort(a, a+n) 就行（内省排序，混了快排 / 堆排 / 插入的优点）——但这五个是理解分治与复杂度的基石。
  • 口诀：冒泡相邻冒大数，选择挑小放前头，插入摸牌插对位；归并分半再合并，堆排塔顶往后放。

👀 一眼看懂：递推与复杂度

  • 🪜 递推：像多米诺骨牌 —— 起点（初始条件）+ 递推式 + 从小到大按顺序算，后面每一项都由前面的项推出来。
  • 🐰 斐波那契：f[i] = f[i-1] + f[i-2]；「上台阶」也是它 —— 走到第 i 阶 = 从 i−1 阶跨 1 步 ∪ 从 i−2 阶跨 2 步。
  • ⏱ 复杂度：数一数基本操作的次数，只看随 n 增长的趋势，不看具体常数。
  • 📏 从小到大：O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2ⁿ)。

⏱ 复杂度速查表

O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2ⁿ)
  • 多项式级（O(1)、O(log n)、O(n)、O(n²)、O(n³)…）：n 大一点也跑得动 —— n = 10⁵ 的 O(n) 约 0.001 秒。
  • 指数级（O(2ⁿ)）：n 每加 1，时间翻倍；n = 40 就要约 3 小时 —— 竞赛 1 秒时限根本跑不动（要到万年级得 n ≈ 65+）。
  • 对应关系：单层循环 → O(n)；双层循环 → O(n²)；每次折半 → O(log n)；递归每层分裂两个子问题 → O(2ⁿ)。
  • n 翻倍时：log n 只 +1、n ×2、n² ×4、2ⁿ 平方 —— 记住这个就能秒判谁快谁慢。

🪜 递推两道经典题

斐波那契 f[1]=f[2]=1　·　上台阶 f[1]=1, f[2]=2　·　都是 f[i] = f[i-1] + f[i-2]
  • 斐波那契：1 1 2 3 5 8 13…每一项 = 前两项之和；项数一大就超过 int（约 21 亿），要开 long long。
  • 上台阶：每次跨 1 或 2 阶，走到第 i 阶 = 从 i−1 阶跨 1 步 + 从 i−2 阶跨 2 步 —— 递推式和斐波那契一模一样！
  • 递推三要素：① 起点（初始条件）② 递推式 ③ 顺序（算 f[i] 时，前两项必须已经算好）。
  • 滚动变量：只记前两个数 a、b，边推边扔 —— 空间从 O(n) 降到 O(1)。

🔍 考场速判 & 易错点

  • 速判：一层循环 → O(n)；两层嵌套 → O(n²)；每次折半（x /= 2、二分）→ O(log n)；递归分裂两个子问题 → O(2ⁿ)。
  • 易错 ①：递推顺序写反 —— 算 f[i] 时 f[i−1] 还没算出来。
  • 易错 ②：斐波那契第 45 项左右就超出 int（约 21 亿），要开 long long。
  • 易错 ③：O(n²) 在 n = 10⁵ 时约 10¹⁰ 次操作 → 必超时；大 n 要找 O(n log n) 或 O(n) 的做法。
  • 易错 ④：大 O 忽略常数（O(2n) 就写 O(n)），但数量级必须分清 —— O(n²) 和 O(n log n) 差 5000 多倍。
